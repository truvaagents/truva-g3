How deep can you actually debug?

The observability chapter asked whether spans exist and how they nest. This companion asks the question you only feel at 2 a.m.: when the agent gives a wrong answer, can you see the exact prompt it sent, the visible reasoning it produced, the tool it called with which arguments, and what came back — the full ReAct loop? And is that visibility free, hidden behind a flag, or locked to a vendor? A source-grounded infographic across the same ten frameworks.

1Three layers of telemetry

"I have tracing" can mean three very different things. Almost every framework gives you the first layer for free. The layer that actually lets you debug a wrong answer — the verbatim content — is a separate decision, and the layer that decides whether you're trapped is a third. Chapter 1 measured Layer 1. This page is about Layers 2 and 3.

1
Metadata — structure & numbers

Span shape, model name, token counts, latency, finish reason, error type. Tells you that an LLM call happened and how long it took — never what was said.

Chapter 1 lives here · on by default almost everywhere
2
Content — the words themselves

The verbatim prompt, the model's completion (including any visible reasoning it emits), the tool name + arguments, and the tool's result. This is what you read to understand why the agent did the wrong thing.

Often gated behind a "sensitive data" flag · the subject of this page
3
Destination — where it can go

Is the content emitted as vendor-neutral OpenTelemetry you can point anywhere, or is the only well-paved path a specific SaaS product you'll keep paying for?

Free vs paid & lock-in · §5 and §6

The trap to avoid

A framework can score "usable spans on day one" in Chapter 1 and still show you not a single prompt without extra work. MS Agent Framework is the textbook case: you get spans and token counts out of the box, but the prompt and response stay dark until you flip a sensitive-data switch37. Semantic Kernel is stricter still — its LLM spans stay off until you set one of its two diagnostics flags (only a bare execute_tool span is emitted ungated), and content needs the sensitive one34. That gap — between "I have tracing" and "I can read what my agent actually said" — is, in our experience, one of the most common production surprises.

2What "going deep" actually means

Debugging an agent means replaying its reasoning loop. A single step has four things worth capturing — and a framework can capture any subset. "It logs LLM calls" usually means only the first and maybe the second. True depth means all four, every step, verbatim.

Input
Prompt sent

System instructions + user message + the entire prior conversation, exactly as serialized to the model.

Capture point 1 →
Thought
Completion

The model's raw output text — including any visible "thought" it emits before an action. (Hidden reasoning tokens aren't returned by providers, so they can't be traced.)

Capture point 2 →
Action
Tool call + arguments

Which tool the model chose and the actual arguments it passed — not just "a tool ran".

Capture point 3 →
Observation
Tool result

The verbatim content the tool returned, which feeds the next reasoning step and closes the loop.

Capture point 4

Why all four, not just the call

In practice, many wrong answers aren't model failures — they're loop failures. The tool returned stale data (you need capture 4), or the model hallucinated an argument (capture 3), or the prompt template silently dropped a variable (capture 1), or the reasoning went sideways before the call (capture 2). Miss any one capture point and you're guessing about that class of bug. The matrix below scores each framework on whether it emits all four to a backend you control.

How to read this

Six frameworks emit the full loop to a backend you control with no per-field heroics: ADK, Mastra, Genkit and Rig do it on by default; MS Agent Framework does it the moment you flip the sensitive-data flag, and Semantic Kernel the moment you set its sensitive flag (which also switches on the LLM spans and metrics). LangChain / LangGraph also capture everything verbatim — export itself is opt-in (one env var), and the real question is the destination, covered next. The two genuine gaps are CrewAI (its native telemetry is anonymized; content needs an add-on or its own SaaS) and LangChain4j (official telemetry is metadata-only; content is yours to wire).

What separates the tiers

The top tier costs you one exporter and nothing else — the words are already on the spans. The second tier is identical in fidelity; the only difference is a deliberate, sane default: Microsoft ships content off so you don't accidentally stream user PII to a dashboard, and you opt in per environment (Agent Framework still emits spans + metrics meanwhile; Semantic Kernel gates even its LLM spans behind a diagnostics flag — either flag enables them). The third tier captures everything too, but makes you pick a route — point LangChain at your own OTLP collector, or drop OpenLIT in front of CrewAI. Only LangChain4j leaves the content emission entirely to you.

5Free, flag-gated, or paid?

The headline first, because it cuts against the reputations: capturing the content is free and open-source in all ten frameworks. You never pay to record the prompt and response. What's sometimes paid is the destination — the hosted UI you choose to send it to — and that is always optional.

Free forever — the data

Open-source instrumentation, in every framework

  • Recording the full ReAct loop (prompt, completion, tool args, tool result)
  • Exporting it as vendor-neutral OpenTelemetry to a collector you run — turnkey in most; for Genkit and Rig the spans are standard OTel but you register the exporter yourself
  • Self-hosted backends: Jaeger, Grafana Tempo, OpenTelemetry Collector, Genkit's local Dev UI, your own log store

Optional & paid — the destination

Convenient hosted UIs & evals — never required to see content

  • LangSmith (LangChain family) · Mastra Cloud · CrewAI AMP
  • Azure Application Insights (SK, MS Agent Framework)
  • Google Cloud Trace / Genkit Monitoring (ADK, Genkit)
  • Third-party SaaS: Datadog, Langfuse, Arize, Braintrust, &c.

The two reputations worth correcting

"LangChain means paying for LangSmith" and "CrewAI tracing means CrewAI's cloud" are both now escapable. LangChain's SDK can send traces only to your own OTLP collector — its LANGSMITH_OTEL_ONLY mode bypasses LangSmith79; CrewAI's execution content can be exported to any OTLP backend through a free OSS instrumentor like OpenLIT, which logs prompts and completions to span attributes by default1770. The paid products buy you a polished UI and eval tooling — not access to your own telemetry.

6Vendor lock-in spectrum

"Pure telemetry" means the content is standard OpenTelemetry you can repoint at any backend on a config change. "Lock-in" means the well-paved path runs through one vendor and getting out is real work. Here's where each framework sits.

None — pure OTel
Semantic Kernel MS Agent Framework Mastra Rig LangChain4j

Standard gen_ai.* attributes / events (Mastra uses its own span format instead, but ships ~10 exporters in-tree, incl. OTel). Swap backends freely.

Minor caveat — Google-flavored
Google ADK Genkit

Content travels on valid OTel spans (vendor-neutral transport), so it goes anywhere — but on Google-specific attribute keys rather than the gen_ai.* conventions, so it renders best in Google Cloud. ADK uses gcp.vertex.agent.* keys19; Genkit uses genkit:input/genkit:output and ships only a GCP prod exporter, which truncates5052.

The nuance most comparisons miss

Lock-in here is about the default path, not a hard wall. Every framework's content can ultimately reach a neutral backend, because it all rides on OpenTelemetry primitives. The question is how much that costs you: nothing for the green group, a slightly less polished view for the Google pair, a deliberate config choice for the LangChain family, and an extra component you install for CrewAI.

Decision guide

Pick by the constraint you actually have.

TURNKEY DEPTH

"I want to read every prompt & response out of the box"

ADK, Mastra, Genkit, Rig. Full ReAct content is on the spans by default — attach an exporter and you're reading the loop. Genkit's local Dev UI is the fastest path to an untruncated inspector.

PII-SAFE BY DEFAULT

"I want metadata always, content only when I say so"

MS Agent Framework, Semantic Kernel. Agent Framework ships spans + token metrics on, with content one explicit sensitive-data flag away. Semantic Kernel is stricter — even its LLM spans stay off until you enable a diagnostics flag — a posture some teams prefer for regulated workloads where nothing should emit unasked.

NO VENDOR, EVER

"I never want to depend on a SaaS"

SK, MS Agent Framework, Mastra, Rig, LangChain4j. All exportable to self-hosted Jaeger or Tempo with no SaaS in the path — SK, Agent Framework and Rig on standard gen_ai.* OTel; Mastra via its in-tree OTel exporter (own span format). LangChain4j is the only one where you must write the content listener yourself.

FREE TRACE UI

"I want a great trace UI without paying"

Genkit (local Dev UI, untruncated) and the LangChain family via the free LangSmith tier (~5K traces, 14-day retention)10 — with a documented OTLP escape hatch if you outgrow it.

WATCH-OUTS

"Where will I be surprised?"

CrewAI — core telemetry is anonymized; add OpenLIT or you'll see no content11. LangChain4j — official modules are metadata-only57. Genkit — cloud export truncates at 128k52. ADK — content defaults off on managed Cloud deploy unless you set the env var yourself24.

BOTTOM LINE

The one-sentence verdict

Capturing the full ReAct loop is free everywhere; six frameworks make it easy and vendor-neutral; the real differences are a flag (Microsoft), an add-on (CrewAI), or your own code (LangChain4j) — not a paywall.
